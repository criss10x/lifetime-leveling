Hapus Akun

Data lokal

Menghapus instalasi aplikasi akan menghapus progres yang hanya tersimpan secara lokal di perangkat.

Hapus backup akun

Kirim email, sebaiknya dari akun Google yang digunakan untuk backup, dengan subjek atau frasa persis: Delete my Muslim Leveling account. Permintaan email akan menghapus akun dan seluruh backup data sisi server dalam tujuh hari. muslim.leveling@gmail.com.

Jika tidak pernah masuk

Jika Anda tidak pernah masuk dengan Google, progres hanya berada di perangkat dan tidak ada backup server yang perlu dihapus.
